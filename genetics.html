法布瑞氏症怎麼遺傳？

法布瑞氏症是性聯遺傳疾病，致病基因（GLA 基因）位在 X 染色體上。

本頁重點
  • 父親是患者：只會遺傳給女兒，不會遺傳給兒子。
  • 母親是帶因者：每一胎不論男女，都有 50% 機率遺傳到。
  • 女性帶因者也可能出現症狀，不是「只帶基因、不會生病」。

為什麼男性影響較大？

男性只有一條 X 染色體（XY），女性則有兩條（XX）。當男性唯一的 X 染色體帶有缺陷，就沒有另一條正常的 X 可以補足，所以對男性的影響較大。

女性帶因者（一條 X 染色體有缺陷、另一條正常）有時也會出現疾病的某些症狀，但通常較輕微。

遺傳的規則是：若父親的 X 染色體帶有法布瑞氏症基因，只會遺傳給女兒；若母親其中一條 X 染色體帶有法布瑞氏症基因，則每個孩子（不論兒女）都有 50% 機率遺傳到。

女性帶因者的酵素檢測

女性帶因者的酵素活性差異很大，這和女性兩條 X 染色體中，每個細胞會隨機關閉其中一條（X 染色體隨機不活化）有關。因此單靠酵素活性檢測，無法完全確認女性是否為帶因者，需要搭配基因檢測。

初稿・待醫師審閱

家人要不要檢查？

當家中有一人確診，代表其他家人也可能帶有相同的基因變異。建議：

  • 由醫師或遺傳諮詢師協助畫出家族譜，找出可能帶有基因的親屬（例如病人的母親、兄弟姊妹、女兒，及母系親屬）。
  • 有需要的家人安排基因檢測；即使目前沒有症狀，及早知道也能及早追蹤。
  • 計畫懷孕前，可先接受遺傳諮詢，了解生育選擇。
